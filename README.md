# Alex Bzdel - Modern Portfolio

A modern, responsive portfolio website showcasing my work as a Data Engineer and ML Engineer.

## 🚀 Features

- **Modern Design**: Clean, professional layout with gradient accents and smooth animations
- **Responsive**: Fully responsive design that works perfectly on all devices
- **Interactive**: Smooth scrolling, hover effects, and micro-interactions
- **Fast Loading**: Optimized for performance with modern web standards
- **Accessible**: Built with accessibility in mind

## 🎨 Design Highlights

- **Hero Section**: Eye-catching introduction with animated profile image
- **Project Showcase**: Interactive project cards with hover effects and links
- **Experience Timeline**: Clean timeline layout for professional experience
- **Contact Form**: Functional contact form with validation
- **Mobile Navigation**: Hamburger menu for mobile devices

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern CSS with Grid, Flexbox, and animations
- **JavaScript**: Vanilla JS for interactions and animations
- **Font Awesome**: Icons
- **Google Fonts**: Inter and JetBrains Mono fonts

## 📱 Responsive Design

The portfolio is fully responsive and optimized for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (320px - 767px)

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No build process required.

## 🎯 Key Sections

1. **Hero**: Professional introduction with call-to-action buttons
2. **About**: Personal story, skills, and statistics
3. **Experience**: Professional timeline with key achievements
4. **Projects**: Interactive showcase of featured projects
5. **Contact**: Contact information and form

## 🔧 Customization

To customize the portfolio:

1. **Content**: Edit the HTML content in `index.html`
2. **Styling**: Modify colors, fonts, and layout in `styles.css`
3. **Interactions**: Update JavaScript behavior in `script.js`
4. **Images**: Replace images in the `resources/` folder
